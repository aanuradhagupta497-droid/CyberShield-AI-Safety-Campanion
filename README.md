# CyberShield - Your AI-Powered Digital Safety Companion

> "Grammarly for Cyber Safety" - An always-available safety layer for everyday digital decisions.

## Problem
Cyber threats reach people everywhere - SMS, WhatsApp, email, calls. Users can't recognize a scam before they act. Help arrives too late after they have already clicked or paid.

## Solution
CyberShield is an AI-powered personal cybersecurity assistant that flags cyber risks while people interact digitally, just like Grammarly flags writing mistakes.

### How it Works
Fear -> Urgency -> Trust -> Action is the trap. CyberShield detects:
- Urgent language
- KYC / Banking request
- Suspicious link
- Sensitive-data ask
- Risk Level: HIGH/MEDIUM/LOW + Safe Action Recommendation

Example: "Your bank account will be blocked today. Complete KYC immediately..."
-> Detected as HIGH risk, Recommendation: Don't click, Verify via official bank app.

## Key Features
- Real-time scam detection across channels
- AI-powered risk scoring
- Simple safe-action guidance for non-technical users
